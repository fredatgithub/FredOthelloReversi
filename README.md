# Othello | Reversi

Jeu d'Othello pour Windows, développé avec WPF et .NET 9.

Lancez `FredOthelloReversi.sln`, puis jouez les pions noirs contre l'ordinateur
sur le plateau 8 × 8. Les coups légaux sont signalés par des points dorés ;
le score est actualisé après chaque coup. La partie se termine lorsque aucun
des deux joueurs ne peut jouer. Utilisez **Nouvelle partie** pour recommencer.
